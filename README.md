## SmileBeen · 임베디드 작업실

프로젝트를 통해 임베디드를 공부한다.
임베디드 엔지니어링 로드맵의 필수 · 권장 칸을 기준으로 프로젝트를 고르고, 한 칸씩 채운다.
알면 간단하지만 모르면 계속 막히는 문제를 정리하고, 영상을 보며 그대로 따라 구현할 수 있게 기록한다.

- 출발: 리눅스 애플리케이션 C 개발 (운영체제 · 스레드 · IPC · 네트워크 · LTE)
- 넓히는 중: 마이크로컨트롤러 · 부트로더 · 임베디드 보안 · HIL 시험 자동화
- 진행 중: STM32 서명 OTA 시험대
